## Blogs and Articles
* [Superpowers: How I'm using coding agents in October 2025](https://blog.fsck.com/2025/10/09/superpowers/) - great blog on "state of the art" Claude Code usage as of October 2025 
* [Fixing Claude Code's amnesia](https://blog.fsck.com/2025/10/23/episodic-memory/) - talks about a memory mechanism to enhance Claude's abilities as you work with it over time
* [ambient-code.ai](https://ambient-code.ai/) - Jeremy Eder's blog, lots of good posts on AI assisted enterprise software development
* [Specification-Driven Development (SDD)](https://github.com/github/spec-kit/blob/f205fa3b58ab3a409bf0432dbafc9d2713b4b9bb/spec-driven.md) - spec-kit's design philosophy
* [Claude Code: Behind-the-scenes of the master agent loop](https://blog.promptlayer.com/claude-code-behind-the-scenes-of-the-master-agent-loop/) - reverse engineered claude code break down of their master agent loop that breaks down a request into tasks and works them to completion
* [12-Factor Agents - Principles for building reliable LLM applications](https://github.com/humanlayer/12-factor-agents) - What are the principles we can use to build LLM-powered software that is actually good enough to put in the hands of production customers?
* [Claude Agent Skills: A First Principles Deep Dive](https://leehanchung.github.io/blogs/2025/10/26/claude-skills-deep-dive/) - very thorough analysis of how Claude Code agent skills work

## Videos

## Repos

* [spec-kit](https://github.com/github/spec-kit) - framework for incorporating spec driven development into your workflows
* [ambient code](https://github.com/ambient-code) - Red Hat "software factory" (mostly prototype currently)
* [agentic-development-plugins](https://github.com/jsell-rh/agentic-development-plugins) - expands on spec-kit a bit
* [Claude superpowers](https://github.com/obra/superpowers) - claude plugin, great repo to learn how to develop your own claude commands, agents, skills to improve both your's and Claude's effectiveness
* [Claude Episodic Memory](https://github.com/obra/episodic-memory) - claude plugin to improve Claude's long term memory
* [Claude Code Plugins: Orchestration and Automation](https://github.com/wshobson/agents/tree/main) - lots of agents/skills for reference and use
